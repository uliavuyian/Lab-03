# Lab 03: Functions as Objects, Lambda, Closures

![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python&logoColor=white)

## 📋 Description

A hands-on lab exploring Python's functional programming features: first-class functions, lambda expressions, closures, and the `nonlocal` keyword.

## 🐍 Python Version

Python 3.10+

## 🚀 How to Run
```bash
python src/main.py
```

## ✅ Implemented Tasks

| Task | Topic | Description |
|------|-------|-------------|
| **A** | First-class functions | `apply_twice(func, x)` — applies a function to `x` twice |
| **B** | Lambda + sorting | Sorts a list of tuples by age and name using `sorted()` with `lambda` |
| **C** | Function factory | `make_multiplier` — returns a new function using closures |
| **D** | Stateful closure | Counter implementation using closures and `nonlocal` |
| **E** | `def` vs `lambda` | Comparison showing both behave identically |
| **F** | Functional pipeline | Processes a number list using `filter`, `map`, and `sum` |
