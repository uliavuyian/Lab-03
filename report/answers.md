# LAB03: Functions as Objects, Lambda, Closures

## 1. What does it mean that functions in Python are first-class objects?

It means that functions in Python are like normal values. You can put them in variables, send them to other functions, return them from a function, or keep them in lists or other collections.

---

## 2. What is the difference between a function defined with `def` and a `lambda` expression?

A `def` function has a name and can do many things inside. A `lambda` is a small, unnamed function that does only one thing.

---

## 3. What is a closure?

A closure is a function that "remembers" some values from outside even after the outside function has finished.

---

## 4. In what situations are closures useful?

Closures are useful when you want to keep a value for later, or when you want to make a function that makes other functions.
